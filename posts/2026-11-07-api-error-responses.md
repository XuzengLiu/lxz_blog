## 约定机器怎么判断

HTTP 状态码说明错误的大类，响应体里的 `code` 则告诉调用方具体发生了什么。保留一条适合展示给人的提示，调用方就不用从提示文字中猜下一步怎么做。

```json
{
  "code": "TASK_NOT_FOUND",
  "message": "没有找到该任务。请核对任务 ID。"
}
```

## 把三种场景分开测试

- 格式错误的任务 ID：确认接口返回 400 和已约定的错误码。
- 格式正确、实际不存在的任务 ID：确认返回 404。
- 临时不可用的查询服务：模拟上游依赖失败，确认错误提示指导用户稍后再试。
